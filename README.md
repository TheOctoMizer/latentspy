# LatentSpy

LatentSpy

## Installation

### Standard Installation (CPU)
```bash
pip install latentspy
```

### CUDA/GPU Installation
For GPU acceleration (requires Python < 3.11):

```bash
pip install latentspy[cuda]
# or
pip install latentspy[gpu]
```

### Development Installation
```bash
git clone <repository>
cd latentspy
pip install -e .
```

For GPU support (Python < 3.11):
```bash
pip install -e .[cuda]
```
